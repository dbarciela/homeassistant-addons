# Google Antigravity Home Assistant Add-ons

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fdbarciela%2Fhomeassistant-addons)

![Google Antigravity Smart Home Web UI](addons/antigravity-cli/web_ui_preview.png)

## Installation

Add this repository URL to your Home Assistant Supervisor Add-on store repositories:

```text
https://github.com/dbarciela/homeassistant-addons
```

## Available Add-ons
 
* **[Antigravity CLI](addons/antigravity-cli/)** — Run Google Antigravity CLI (`agy`) inside Home Assistant with dual Web UI/Terminal, 88+ HA MCP tools, mobile-responsive monitoring dashboard, and remote control daemon.
